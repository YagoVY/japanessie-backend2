🧪 Vertical ー (Chōonpu) Rotation Test

📋 What This Tests:
This test verifies that the ー character rotates 90 degrees to display as a vertical pipe (|) when rendering vertical Japanese text. You should see the ー appearing as | (vertical) instead of ー (horizontal).
✅ Visual Inspection Guide:
  • Look for the ー character - it should appear as a vertical pipe |
  • The vertical pipe should be centered between characters
  • The vertical pipe should be positioned slightly below center for proper spacing
  • Compare "Before" (no rotation) vs "After" (with rotation) for each test
